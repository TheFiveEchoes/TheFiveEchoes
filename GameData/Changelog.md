# Changlog

This is the changelog for the The Five Echoes Planet Pack. This changelog features all
change made to The Five Echoes starting on May 21st 2026 (UTC Time Zone), with newer
versions being at the top.

## Beta 0.5.0 - Backyard Bananza

Features:
- The following celestial bodies have been implemented:
    - Verlod
    - Yaru
    - Yelern
- Added Parallax Continued Scaled & Terrain for Verlod, Yaru & Yelern
- Finalized Verlod's Rings
- Sunflare updates
- Celestial descriptions for Verlod, Yaru & Yelern
- Added Axial Tilt for Verlof, Yaru & Yelern
- Added Axial Tilt into the settings
- Added a time offset option into the settings
- Added custom Kronometer months & time display
- Added a master plugin that for now is responsible for automatic cache deletion & offset time if those settings are enabled
