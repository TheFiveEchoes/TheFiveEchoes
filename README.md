# The Five Echoes

**_The Five Echoes_ is a planet pack for Kerbal Space Program that aims at providing a vast amount of different celestial objects to explore. With a system replacer and 15 interstellar systems in planning, plus an integrated story mode, there will certainly be a lot to discover.**

>[!IMPORTANT]
> _The Five Echoes_ is currently in development. Completed steps towards each release - beta or full - can be found in the Progress.md file
